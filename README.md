# NAVI

Smart wheelchair, UCF Senior Design Group 7. This is the `pcb-ready` branch.

| Folder | What it is |
|---|---|
| [`NAVI/`](NAVI/) | **The system for the final PCBs.** Pi code (vision, depth, control), ESP32 firmware, tests and tools. Its README has the test status of every part: tested, partly tested, not working, or not tested yet. |
| [`bench-history/`](bench-history/) | Older trees that were used for testing on the dev-kit bench, with what each one tested and how. Kept for the record; not for new work. |
